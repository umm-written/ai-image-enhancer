# AI Image Enhancer 🪄

A simple web application that automatically enhances image quality using AI.

## 🚀 How It Works

1. **Upload**: Select an image file in the web app.
2. **Process**: The backend sends the image to an AI enhancement service.
3. **Preview**: View and compare the original and enhanced images side-by-side.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS (`ai-image-enhancer/`)
- **Backend**: Express.js, Node.js (`ai-image-enhancer/backend/`)
- **AI API**: TechHK / PicWish API

## ⚡ Quick Setup

### 1. Backend

```bash
cd ai-image-enhancer/backend
npm install
npm start
```

### 2. Frontend

```bash
cd ai-image-enhancer
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
